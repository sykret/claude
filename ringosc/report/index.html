PTM 180nm – 7nm · planar bulk + FinFET · ngspice-45.2 (OSDI) · 21-stage ring oscillator

PTM 링 오실레이터 노드 비교

같은 셀 토폴로지로 그린 레이아웃에서 배선 parasitic 을 추출해 12개 노드(planar bulk 7개, FinFET 5개), 20개 소자 코너에서 주파수·전력·에너지·누설을 비교했습니다. 소자만 있는 경우, 레이아웃 추출, 단마다 10 µm / 100 µm 배선을 더한 경우를 함께 시뮬레이션해 배선이 스케일링에서 차지하는 비중을 분리했습니다.

핵심 결과

  1. planar 의 한계와 FinFET 의 반등. 소자만의 주파수는 180nm 0.51 GHz → 22nm bulk HP 4.04 GHz 로 오르다 45nm 이후 둔화되지만(45→22nm +18%), FinFET 으로 넘어가며 20nm 11.0 GHz → 7nm 40.6 GHz 로 다시 크게 뛰어오릅니다. 핀 하나가 최소 bulk 트랜지스터보다 2배 넘는 전류(약 115–140 µA/fin)를 내면서 소자 커패시턴스는 더 작기 때문입니다.
  2. 배선 비중은 노드마다 커지고, FinFET 에서 급증. 최소 레이아웃의 짧은 배선만으로도 주파수 손실이 180nm 13% → 22nm 22% → 7nm HP 43% (LSTP 49%)로 늘어납니다. 소자가 빨라지고 작아질수록 같은 셀 안의 배선이 상대적으로 무거워집니다.
  3. 고정 길이 배선에서는 이득이 사라짐. 단마다 100 µm 배선을 붙이면 가장 빠른 노드는 130nm bulk(0.241 GHz)이고, 14nm FinFET(0.230)이 그와 비슷하며 7nm 는 0.166 GHz 로 다시 느려집니다. 22nm bulk 는 0.100 GHz 로 최저입니다. 배선이 지배하는 회로에서는 소자 세대가 바뀌어도 속도가 거의 오르지 않습니다.
  4. 원인: 구동 저항과 배선 R. 배선 C/µm 은 노드와 무관하게 0.15–0.20 fF/µm 입니다. 최소 인버터의 등가 저항은 planar 에서 6.1 kΩ(130nm) → 19.7 kΩ(22nm)로 커졌다가 FinFET 에서 7–9.5 kΩ 로 회복되지만, 금속 r 이 0.19 → 100 Ω/µm 로 500배 늘어 7nm 에서는 100 µm 배선 자체의 RC(55 ps)가 단 지연 143 ps 의 약 40%를 차지합니다.
  5. 에너지는 CV² 로 계속 감소, 누설 밀도는 높게 유지. 사이클당 에너지는 702 fJ → 1.9 fJ (약 370배) 줄어듭니다. 누설 밀도는 180nm 0.16 → 22nm bulk 73 nW/µm² 로 늘고, FinFET 에서도 48–78 nW/µm² 수준입니다. 저누설 코너(LP/LSTP)는 누설이 110–290배 작은 대신 planar LP 는 3.4–4.4배, FinFET LSTP 는 1.4–2.1배 느립니다.

실험 구성

회로는 enable 용 NAND2 1개와 인버터 20개로 된 21단 링입니다. planar 노드는 drawn L = 노드, Wn = 2L, Wp = 4L 이고 PTM 카드의 xl 이 drawn 과 printed 게이트 길이 차이를 보정합니다. FinFET 노드는 PTM-MG 카드의 L 과 핀 형상을 쓰고, 최소 크기로 NMOS·PMOS 각 1 fin 입니다(PMOS 핀 전류가 NMOS 의 0.88–0.93배라 1:1 이 균형).

네 가지 구성을 노드·코너마다 시뮬레이션했습니다.

  • 소자만: 소자 모델의 parasitic 만 반영(planar 는 레이아웃의 AD/AS/PD/PS 포함), 배선 없음
  • 레이아웃 추출: 모든 신호 net 의 M1/M2/게이트 배선과 콘택·비아를 RC π 래더로 추가
  • +10 µm / +100 µm: 레이아웃 추출에 단마다 중간층 배선(분포 RC)을 더함 — 셀 사이를 실제로 라우팅할 때의 부하

주파수는 v(n1) 의 VDD/2 상승 교차 간격, 전력은 정수 주기 동안 I(VDD) 적분, 누설은 EN = 0 정지 상태의 DC 전류입니다.

FinFET 모델. PTM-MG 는 BSIM-CMG(HSPICE level 72, 105.03) 카드입니다. 공개 BSIM-CMG 111.0.0 Verilog-A 를 OpenVAF 로 OSDI 라이브러리로 컴파일하고, OSDI 를 켠 ngspice-45.2 에서 불러왔습니다. 111.0.0 에 없는 14개 파라미터 (lmin/lmax 등 binning 한계, version, capmod·coremod 등 대부분 0 인 플래그, vasat·vasatcv·ldg·nseg)는 제외했습니다. planar 노드 결과는 ngspice-42 와 45.2 에서 동일함을 확인했습니다.

배선 모델. 금속 폭·간격은 레이아웃 규칙 그대로 3λ, 두께 = AR × 폭, ILD 높이 = 두께입니다. C 는 PTM 배선 모델의 closed-form 식(양옆 이웃 + 접지면, Miller 계수 1), R 은 크기 효과와 배리어를 포함한 유효 비저항 ρeff 로 계산합니다. AR, k, ρeff, FinFET 의 M1 피치는 업계·ITRS 추세 수준의 가정치입니다. 게이트는 8 Ω/□, 콘택 저항은 10 Ω × (180/노드)로 둡니다.

레이아웃

레이아웃은 SCMOS 계열의 단순화된 λ 규칙으로 생성했습니다. planar 노드는 λ = L/2, FinFET 노드는 실제 셀 크기에 맞도록 λ = M1 피치/6 입니다(7nm 인버터 107 × 253 nm, 실제 2 CPP × 6-track 셀과 비슷). 모든 노드가 λ 단위로 같은 도면이라 배선 길이는 λ 에 비례합니다. 도형마다 net 이름을 달아 두고 그로부터 R·C 를 계산합니다. GDS 파일은 ringosc/results_nodes/layout/ 에 있습니다.

분석

고정 길이 배선: 무엇이 지연을 정하나

+100 µm 구성의 단 지연에서 레이아웃 구성의 단 지연과 배선 자체의 Elmore 항(0.38·Rw·Cw)을 빼고 0.69·Cw 로 나누면 최소 인버터의 등가 구동 저항이 나옵니다. planar 에서는 Reff ≈ VDD / (Ion/µm × W) 에서 Ion/µm 이 포화되고 W 가 노드에 비례해 줄어 Reff 가 계속 커집니다. FinFET 에서는 핀 하나의 유효 폭(2·Hfin + Tfin ≈ 43–71 nm)과 전류가 커서 Reff 가 7–9.5 kΩ 로 내려오지만, 이번에는 배선 R 이 커집니다. 7nm 에서 0.38·Rw·Cw 가 55 ps 로 0.69·Reff·Cw(87 ps)에 근접합니다. 긴 배선에 구동기 크기 키우기, 리피터, 상위 금속층(두꺼운 배선) 사용이 필수인 이유입니다.

짧은 배선의 비중

최소 레이아웃에서도 배선 손실이 13% → 43%로 커지는 것은, 소자 커패시턴스는 노드에 비례해 줄어드는 반면 배선 C/µm 은 거의 줄지 않아 같은 λ 길이의 배선이 상대적으로 무거워지기 때문입니다. 단당 Ceff 중 배선 몫은 180nm 13% → 22nm 22% → 7nm 40% 수준입니다. 실제 FinFET 공정에서는 여기에 게이트–콘택(MOL) 결합 커패시턴스가 더해져 비중이 더 큽니다.

전력과 에너지

링 오실레이터는 부하 C 가 커지면 주파수가 같은 비율로 떨어지므로 P = N·C·V²·f 에서 C 가 상쇄됩니다. 그래서 노드 비교는 전력보다 사이클당 에너지(N·Ceff·V²)가 적절합니다. Ceff/단은 180nm 10.3 fF → 22nm 0.58 fF → 7nm 0.18 fF, VDD² 는 3.24 → 0.49 로 줄어 에너지가 약 370배 감소합니다. 20nm FinFET 은 VDD 가 22nm bulk(0.8 V)보다 높은 0.9 V 라 사이클당 에너지가 약간 큽니다.

저누설 코너

planar LP 는 Vth 가 높아(약 0.62–0.69 V) VDD 를 올려도 HP 보다 3.4–4.4배 느립니다. FinFET LSTP 는 같은 VDD 에서 1.4–2.1배 느릴 뿐이며 누설은 150–290배 작습니다. 핀 구조의 게이트 장악력 덕분에 저누설 코너의 속도 손해가 planar 보다 훨씬 작습니다. 다만 노드가 작아질수록 HP/LSTP 속도 차가 커집니다(20nm 1.4배 → 7nm 2.1배).

모델 경계에서의 불연속

180nm 카드는 PTM beta 의 BSIM3 모델로 접합 커패시턴스가 130nm 이하 카드보다 7배 커서 180 → 130nm 향상(2.9배)이 과장되어 있습니다. 22nm bulk → 20nm FinFET 의 2.7배 도약도 모델 계열이 바뀌는 지점입니다. PTM-MG 카드에는 MOL parasitic 이 거의 없어 FinFET 의 절대 주파수(7nm 소자만 40 GHz, 단 지연 1.2 ps)는 낙관적인 상한으로 봐야 합니다. 같은 계열 안의 추세 비교가 더 신뢰할 만합니다.

한계

  • PTM-MG 카드는 BSIM-CMG 105.03 기준인데 공개 111.0.0 모델로 시뮬레이션했습니다. 버전 간 기본값과 일부 식이 다르고 111.0.0 에 없는 14개 파라미터를 제외했으므로, PTM 이 HSPICE 로 발표한 값과 조금 다를 수 있습니다.
  • λ 규칙은 실제 디자인 룰을 단순화한 것이고, 실제 공정은 λ 처럼 균일하게 축소되지 않습니다(게이트·금속·핀 피치가 각각 다르게 스케일). FinFET 은 λ = M1 피치/6 이라는 별도 기준을 씁니다.
  • 배선 AR·k·ρeff, FinFET M1 피치, 콘택 저항은 가정치입니다. 추출은 레이어별 closed-form 모델로 한 근사 PEX 이며, MOL 결합 커패시턴스·상부 접지면·3차원 프린지·인덕턴스는 빠져 있습니다.
  • 공정 편차(Monte Carlo), 온도·전압 스윕은 노드 비교에 포함하지 않았습니다(45nm 단일 노드 스윕은 ringosc/README.md 참고).
  • planar 누설 DC 해석에서만 BSIM4 rbodymod=0 을 사용합니다(body 저항망으로 인한 비물리적 DC 해 회피).
